# VpnRunner

Одна кнопка **Run**:

1. подключает рабочий **Cisco** (через openconnect: логин, пароль и код Google Authenticator подставляются сами);
2. поднимает **VPN по подписке** (через sing-box; подписок может быть несколько);
3. раскидывает трафик по правилам:

| Куда идёт трафик | Через что |
|---|---|
| Рабочие подсети и домены | Cisco |
| Российские сайты (.ru, .рф, .su, список российских сервисов, российские IP) | напрямую |
| Ваши сайты с пометкой «Напрямую» | напрямую |
| Ваши сайты с пометкой «Через VPN» (сильнее правила для российских сайтов) | VPN |
| Всё остальное | VPN |

**Stop** выключает в обратном порядке: сначала VPN, потом Cisco.

В строке меню (сверху) — значок-щит: серый — выключено, жёлтый — подключается, зелёный — работает. В его меню: «Включить», «Выключить», «Открыть окно», «Выход». Закрытие окна только прячет его — VPN продолжает работать; совсем выйти (с остановкой VPN) — «Выход» в меню значка.

## macOS

Все команды ниже — **на локальной машине (Mac), в Терминале**.

1. Установить openconnect и sing-box:
   ```sh
   brew install openconnect sing-box
   ```
2. Нужен JDK 17 или новее (у вас он есть, если стоит Android Studio).
3. Запустить из папки проекта:
   ```sh
   ./gradlew run
   ```
   Собрать .dmg:
   ```sh
   ./gradlew packageDmg
   ```
   Готовый файл: `build/compose/binaries/main/dmg/`.

При каждом Run macOS один раз спросит пароль администратора — без root нельзя создать VPN-интерфейсы.

## Windows

1. Установить OpenConnect (консольный клиент) — 64-битный установщик с официальной сборки:
   https://gitlab.com/openconnect/openconnect/-/jobs/artifacts/master/raw/openconnect-installer-MinGW64-GnuTLS.exe?job=MinGW64/GnuTLS
2. Скачать sing-box для Windows (`sing-box-<версия>-windows-amd64.zip`) со страницы релизов
   https://github.com/SagerNet/sing-box/releases и положить `sing-box.exe` в `%APPDATA%\VpnRunner\bin\`
   (или указать путь во вкладке Cisco → «Дополнительно»).
3. Нужен JDK 17+. Запуск — **на локальной машине (Windows), в PowerShell, в папке проекта**:
   ```powershell
   .\gradlew.bat run
   ```
   Собрать установщик:
   ```powershell
   .\gradlew.bat packageMsi
   ```
4. Программа должна работать **от имени администратора**. Если запустить без прав, на главной будет кнопка «Перезапустить от имени администратора».

## Первая настройка

**Подписки.** Вкладка «Подписки» → название + ссылка `https://…` → «Добавить подписку». Серверы появятся в списке на главной. «Авто» выбирает самый быстрый.

Если адрес подписки блокирует провайдер («нет соединения (таймаут)»), программа пробует скачать её через системный прокси и через локальные прокси `127.0.0.1:2080 / 10809 / 7890` (Throne, v2rayN, Clash). Для первого раза достаточно включить Happ или Throne и нажать «Обновить» — подписка сохранится, дальше Run работает и без них. Когда VPN запущен, адреса подписок всегда идут через VPN, и подписки обновляются автоматически после Run.

Программа передаёт сервису подписок идентификатор устройства (`x-hwid`, как Happ) — сервисы с лимитом устройств без него присылают вместо серверов заглушку «App not supported». Компьютер появится в списке устройств сервиса как «VpnRunner». Если сервис всё равно присылает заглушку, обычно лимит устройств исчерпан: удалите лишнее устройство в боте или личном кабинете.

**Cisco.** Вкладка «Cisco»:
- Сервер — то же, что вводите в AnyConnect.
- Логин, группа (если в AnyConnect есть выбор группы).
- Пароль → «Сохранить». Хранится в Связке ключей macOS / в зашифрованном виде (DPAPI) на Windows, не в файле настроек.
- Секрет Google Authenticator — скопируйте из TOTP Vault **секретный ключ** (строка вроде `JBSWY3DPEHPK3PXP`, параметр `secret=` из QR-кода) или целую ссылку `otpauth://…`. После сохранения программа показывает текущий код — он должен совпадать с кодом в TOTP Vault.
- Рабочие подсети (например `10.0.0.0/8`) и домены (например `corp.local`). Если оставить пустым — берутся подсети, которые присылает сервер.
  DNS Cisco спрашивается только про рабочие домены — присланные сервером (их видно в журнале при подключении) и указанные здесь; остальные имена до компании не доходят. Если внутренний сайт не открывается, добавьте его домен сюда. На macOS для каждого рабочего домена создаётся файл `/etc/resolver/<домен>` (помечен `# VpnRunner`, удаляется при Stop), остальные имена резолвит sing-box; если включён другой VPN (Happ), обычные имена может резолвить он. Если сервер присылает «весь трафик через Cisco», программа предупредит: тогда подсети нужно указать вручную.

**Правила.** Вкладка «Правила» → сайт → «Напрямую» или «Через VPN». Правило действует и на поддомены. Если VPN уже работает — нажмите «Применить» (Cisco при этом не переподключается).

## Где что лежит

| | macOS | Windows |
|---|---|---|
| Настройки | `~/Library/Application Support/VpnRunner/settings.json` | `%APPDATA%\VpnRunner\settings.json` |
| Журналы, конфиг sing-box | `~/Library/Application Support/VpnRunner/run/` | `C:\ProgramData\VpnRunner\run\` |

Журналы openconnect и sing-box также видны во вкладке «Журнал».

## Ограничения

- **Другой VPN (Happ и т.п.)** можно не выключать. Такие программы отправляют частные сети (`10.0.0.0/8` и др.) мимо себя через Wi-Fi и этим перебивают маршруты Cisco — VpnRunner при подключении и затем каждые ~10 с забирает рабочие подсети обратно на Cisco, а при отключении возвращает как было (`run/route-fix.log`). Если sing-box остановится сам (например, при сне Mac), он перезапускается.

- **xhttp.** sing-box не поддерживает транспорт xhttp. Если у сервиса есть только такие серверы, они будут пропущены (в журнале будет написано, сколько и почему).
- **Остановка на Windows** завершает процессы принудительно: интерфейсы исчезают вместе с процессами, но сервер Cisco не получает «до свидания» — сессия на его стороне закроется по таймауту.
- **macOS:** скрипт-супервизор с правами root запускает файлы из вашей папки `Application Support`. Так же устроены Throne и другие клиенты; если на Mac есть недоверенные программы под вашим пользователем, это стоит учитывать.
- Списки российских сайтов и IP программа скачивает напрямую с GitHub перед запуском VPN и обновляет раз в 3 дня (`rules/` в папке настроек). Если GitHub недоступен и копии ещё нет, sing-box скачивает их сам через VPN.

## Как устроено

- `core/` — без зависимостей: разбор подписок (vless, vmess, trojan, shadowsocks, hysteria2), генератор конфига sing-box, TOTP (RFC 6238).
- `platform/` — запуск openconnect и sing-box, обёртка над vpnc-script для раздельного туннелирования Cisco, хранение секретов.
- `ui/` — интерфейс на Compose Desktop.
